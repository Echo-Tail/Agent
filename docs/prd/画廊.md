这是一份专为企业内部、电商设计场景量身定制的**精选作品画廊（Gallery）功能产品需求文档（PRD）**。文档采用了标准的 B 端系统规范，聚焦于“创意资产复用”与“员工提效”。

---

# 产品需求文档 (PRD)

**项目名称**：内部电商设计 AI 精选画廊 (Design Gallery)

**文档版本**：v1.0

**主要读者**：前端/后端开发、UI/UX 设计师、测试工程师

---

## 1. 业务背景与用户痛点

* **业务背景**：公司内部员工（设计师、运营）通过 AI 工具生成了大量电商图片。为了沉淀优质视觉资产、避免重复试错、促进团队间灵感碰撞与技术（Prompt）交流，需要建立一个公共的、经过员工自主筛选的“精选作品画廊”。
* **用户痛点**：
* **历史记录冗余**：生图历史包含大量废片，无法直接用于团队参考。
* **尺寸复杂多样**：电商图片包含主图(1:1)、详情页、Banner 等，传统网格布局容易导致图片变形或显示不全。
* **复用效率低**：看到别人生成的优质图片，无法快速获取其 Prompt、工作流参数或原图，资产无法有效沉淀。



---

## 2. 产品核心目标

1. **资产精选化**：提供轻量级的“推送到画廊”机制，确保画廊只展示用户主动挑选的优质成品，而非全部生图历史。
2. **视觉兼容性**：完美兼容电商多尺寸、多比例图片的展示，不裁剪、不变形。
3. **提效工具化**：画廊不仅是“看”的通道，更是“拿来即用”的工具箱，支持一键复制参数、快速复用。

---

## 3. 功能架构与用户旅程

```
[员工生图历史/作品] -> [勾选上传并打标] -> [公共精选画廊展示] -> [点击右侧抽屉] -> [复制Prompt/下载资产]

```

---

## 4. 详细功能需求

### 4.1 功能模块一：作品发布与管理（画廊上游）

* **功能描述**：用户从个人生图历史或本地将满意作品发布到公共画廊。
* **交互逻辑**：
* **入口 1**：在个人历史记录的图片操作项中，增加“发布至画廊”按钮。
* **入口 2**：画廊首页右上角放置“发布作品”按钮，点击后弹出“从历史记录选择”的弹窗（支持多选）。


* **发布表单表项**：
| 字段名称 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 作品图片 | Image | 是 | 自动携带或用户选择，支持读取图片 Exif 信息（如有） |
| 适用类目 | Dropdown | 是 | 级联选择器（如：汽车用品 -> 车载音频 -> 双din车机） |
| 画面风格 | Multi-Select | 是 | 标签选择（如：科技风、写实、3D渲染、场景图、欧美风） |
| 画面尺寸 | Radio | 是 | 自动识别或手动校对：1:1(主图) / 3:4(详情页) / 16:9(Banner) / 其他 |
| 提示词(Prompt) | Textarea | 是 | 自动带入原生成提示词，允许用户编辑优化 |



---

### 4.2 功能模块二：画廊主页视图（瀑布流）

* **功能描述**：画廊核心展示区域，支持多维筛选与高效浏览。
* **页面布局**：顶部为**固定筛选区**，下方为**卡片式瀑布流（Masonry Layout）**。
* **详细需求**：
1. **多维筛选栏**：
* 支持按【品类】、【尺寸比例】、【画面风格】、【生成模型】进行多选组合筛选。
* 支持按【最新发布】、【最高点赞/采纳】进行排序。


2. **卡片式瀑布流设计**：
* **卡片间距**：固定为 `16px`，整体两端对齐。
* **图片渲染**：保持原图宽高比，宽度自适应网格列宽。
* **基本信息底座（固定高度 `72px`）**：图片下方展示：作品标题/品类标签、作者头像及昵称、点赞数。


3. **悬停交互（Hover Effect）**：
* 当鼠标悬停在某张卡片上时，图片上方浮现半透明遮罩层（Black Alpha 40%）。
* 遮罩层上提供 3 个快捷操作按钮：
* **【📋 复制 Prompt】**：点击后气泡提示“Prompt已复制到剪贴板”。
* **【❤️ 点赞/收藏】**：高亮状态切换，更新计数。
* **【🔽 下载原图】**：直接触发浏览器下载高清原图。







---

### 4.3 功能模块三：详情查看（右侧抽屉式展示）

* **功能描述**：用户需要查看详细技术参数时，提供不中断浏览体验的查看方式。
* **交互逻辑**：在瀑布流中点击任意卡片，页面**不跳转、不弹出全屏居中弹窗**，而是从屏幕**右侧平滑滑出抽屉（Drawer）**，宽度占屏幕的 `35%`。左侧瀑布流区域自动遮罩（允许滚动）。
* **抽屉内信息展示规范**：
* **上半部分（视觉区）**：缩略图等比缩放显示，提供“查看大图（灯箱模式）”和“下载”按钮。
* **下半部分（参数区 - 核心）**：
* **正向提示词（Prompt）**：使用代码块样式包裹，右上角带【一键复制】按钮。
* **负面提示词（Negative Prompt）**：同上。
* **技术参数列表**：以表格或 Key-Value 形式展示：底层模型、Sampler、Steps、CFG Scale、Seed、尺寸。
* **业务信息**：上传者、所属项目、适用电商平台、上传时间。


* **底部交互**：支持快捷键 `←` `→` 或点击抽屉顶部的“上一张/下一张”箭头，直接在抽屉内切换查看瀑布流中的相邻图片。

## 5. 非功能性需求与性能指标 (UX/Tech)

### 5.1 图像加载优化（电商场景核心）

* **流式加载与骨架屏**：瀑布流图片必须采用懒加载（Lazy Load）。在图片未加载完成前，显示骨架屏卡片。
* **主色调占位（进阶）**：后端在存储精选图片时，计算并存储图片的主色调（或使用 BlurHash 算法）。前端在加载期间，卡片背景先渲染为该主色调的渐变块，加载完成后平滑淡入（Fade-in）原图。

### 5.2 权限与安全控制

* **可见性控制**：由于是企业内部自用，非本公司域账号（或未登录状态）禁止通过任何外链访问画廊图片及 API。
* **内容管理（管理员权限）**：部门主管或画廊管理员拥有“下架”权限，可对不合规、质量差或涉密、侵权的图片进行画廊下架处理（下架仅从公共画廊移除，不删除用户的个人历史记录）。

2. **水印问题**：内部员工下载精选画廊图片用于外部电商上架时，系统是否需要自动去除或加上特定盲水印以防资产泄露？（需与法务/安全部门确认）。
